# Plantillas de propuestas

Carpeta dedicada al contenido y al diseño de las propuestas comerciales.

| Archivo | Para qué sirve |
| --- | --- |
| `catalog.js` | Secciones editables de la propuesta (resumen, alcance, entregables). |
| `buildProposalText.js` | Genera el texto completo de la propuesta en español. |
| `ProposalDocument.jsx` | Diseño visual de la "hoja" de la propuesta en la vista previa. |
| `printProposal.js` | Maqueta y estilos de la versión imprimible. |

> Los valores guardados en la base de datos son los datos del formulario. El texto visible se genera con `buildProposalText()`.
